# Security Policy

## Reporting Security Vulnerabilities
If you discover a security vulnerability or potential denial-of-service issue in MatRust Studio (such as a parser recursion overflow, container zip-slip, zip-bomb bypass, or sandbox evasion), please report it responsibly.

Please open a private GitHub Security Advisory at:
https://github.com/varunkumar898/MatRust-Studio/security/advisories/new

Or contact the maintainer directly. Please do not open public GitHub issues for undisclosed security vulnerabilities.

## Supported Versions
Only the latest commit on the `main` branch receives active security updates and vulnerability patches.
