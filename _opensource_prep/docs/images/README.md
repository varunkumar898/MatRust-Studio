# Screenshots

Use clear, useful screenshots of MatRust Studio. Keep the original application layout and do not add fake UI, results, or compatibility claims.

## Naming and size

- Use lowercase kebab-case names that describe the view, such as `workspace-sine-wave.png` or `simulink-inspector.png`.
- Prefer PNG for screenshots. Aim for roughly 1200 px wide and a readable 16:9 or 16:10 layout.
- Crop empty desktop space, but keep enough application chrome to identify the view.
- Optimize image size; avoid uploading unnecessarily large captures.

## Privacy and clean-room checklist

- Remove or replace usernames, home-directory paths, machine names, tokens, and private repository names.
- Close private files and remove personal data from editors, dialogs, file lists, terminals, and notifications.
- Do not show proprietary MATLAB, MathWorks, or third-party `.mlapp`, `.mlappinstall`, or `.slx` files.
- Use synthetic examples and project-owned assets only.
- Confirm every visible result is genuine and was produced by the displayed application.

`workspace-sine-wave.png` is a sanitized copy of a user-provided capture. The original attachment was left unchanged; its local paths were replaced and the temporary prep-folder row was removed.
