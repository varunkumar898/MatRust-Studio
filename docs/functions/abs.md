# `abs`

Absolute value and complex magnitude.

## Syntax

```matlab
Y = abs(X)
```

## Description

- `Y = abs(X)`: Returns the absolute value of real elements or complex magnitude sqrt(re^2 + im^2).
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
