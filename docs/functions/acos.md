# `acos`

Inverse cosine.

## Syntax

```matlab
Y = acos(X)
```

## Description

- `Y = acos(X)`: Computes the inverse cosine (in radians) for each element of X.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
