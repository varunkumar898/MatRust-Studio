# `all`

Determine if all array elements are nonzero or true.

## Syntax

```matlab
B = all(A)
B = all(A, dim)
```

## Description

- `B = all(A)`: Tests along dimension dim whether all elements are nonzero or logical true.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
