# `angle`

Phase angle of complex number.

## Syntax

```matlab
P = angle(Z)
```

## Description

- `P = angle(Z)`: Returns the phase angle in radians in the interval [-pi, pi] for each element of Z.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
