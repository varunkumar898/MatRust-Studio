# `any`

Determine if any array elements are nonzero or true.

## Syntax

```matlab
B = any(A)
B = any(A, dim)
```

## Description

- `B = any(A)`: Tests along dimension dim whether any element is nonzero or logical true.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
