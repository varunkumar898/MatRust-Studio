# rea

Filled area 2-D plot.

## Syntax

`matlab
area(Y)
area(X, Y)
`

## Description

- rea(Y) displays the elements of Y as filled area under curves.
- rea(X, Y) plots Y against X with filled area.

## Example

`matlab
x = 1:10;
y = [1 3 2 5 4 7 6 9 8 10];
area(x, y);
`
