# `asin`

Inverse sine.

## Syntax

```matlab
Y = asin(X)
```

## Description

- `Y = asin(X)`: Computes the inverse sine (in radians) for each element of X.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
