# `atan`

Inverse tangent.

## Syntax

```matlab
Y = atan(X)
```

## Description

- `Y = atan(X)`: Computes the inverse tangent (in radians) for each element of X.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
