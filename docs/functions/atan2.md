# `atan2`

Four-quadrant inverse tangent.

## Syntax

```matlab
P = atan2(Y, X)
```

## Description

- `P = atan2(Y, X)`: Computes four-quadrant inverse tangent of Y and X such that -pi <= P <= pi.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
