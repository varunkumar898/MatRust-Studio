# `cell`

Create cell array.

## Syntax

```matlab
C = cell(n)
C = cell(sz1, ..., szN)
```

## Description

- `C = cell(n)`: Constructs an empty cell array of the specified dimensions with each element initialized to [].
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
