# `char`

Convert to character array.

## Syntax

```matlab
S = char(X)
```

## Description

- `S = char(X)`: Converts numeric codes, strings, or cell arrays of character vectors to a char array.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
