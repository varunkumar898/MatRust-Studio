# `chol`

Cholesky factorization.

## Syntax

```matlab
R = chol(A)
```

## Description

- `R = chol(A)`: Computes upper triangular R such that R'*R = A for symmetric positive definite matrix A.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
