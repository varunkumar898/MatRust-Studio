# `conj`

Complex conjugate.

## Syntax

```matlab
Y = conj(X)
```

## Description

- `Y = conj(X)`: Computes the complex conjugate of each element of X (re - 1i*im).
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
