# `conv`

Convolution and polynomial multiplication.

## Syntax

```matlab
C = conv(A, B)
C = conv(A, B, shape)
```

## Description

- `C = conv(A, B)`: Computes 1D discrete convolution of vectors A and B with full, same, or valid shape.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
