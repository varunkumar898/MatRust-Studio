# `cos`

Cosine of argument in radians.

## Syntax

```matlab
Y = cos(X)
```

## Description

- `Y = cos(X)`: Computes cosine of each element of X in radians.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
