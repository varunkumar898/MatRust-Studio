# `cumprod`

Cumulative product.

## Syntax

```matlab
B = cumprod(A)
B = cumprod(A, dim)
```

## Description

- `B = cumprod(A)`: Computes the cumulative product of elements along dimension dim.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
