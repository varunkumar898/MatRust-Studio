# `cumsum`

Cumulative sum.

## Syntax

```matlab
B = cumsum(A)
B = cumsum(A, dim)
```

## Description

- `B = cumsum(A)`: Computes the cumulative sum of elements along dimension dim.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
