# `det`

Matrix determinant.

## Syntax

```matlab
d = det(A)
```

## Description

- `d = det(A)`: Computes the determinant of square matrix A using LU decomposition with partial pivoting.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
