# `diag`

Diagonal matrices and diagonals of matrix.

## Syntax

```matlab
D = diag(v)
v = diag(A)
```

## Description

- `D = diag(v)`: Extracts matrix diagonals or constructs diagonal matrices.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
