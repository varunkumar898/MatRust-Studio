# `diff`

Differences and approximate derivatives.

## Syntax

```matlab
Y = diff(X)
Y = diff(X, n, dim)
```

## Description

- `Y = diff(X)`: Computes differences between adjacent elements along dimension dim.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
