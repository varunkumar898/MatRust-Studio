# `eye`

Identity matrix.

## Syntax

```matlab
I = eye(n)
I = eye(m, n)
```

## Description

- `I = eye(n)`: Constructs an m-by-n matrix with ones on the main diagonal and zeros elsewhere.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
