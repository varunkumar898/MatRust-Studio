# `false`

Logical false array.

## Syntax

```matlab
L = false(n)
L = false(sz1, ..., szN)
```

## Description

- `L = false(n)`: Creates a logical array with all elements set to logical 0 (false).
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
