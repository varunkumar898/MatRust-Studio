# `fieldnames`

Field names of structure array.

## Syntax

```matlab
names = fieldnames(s)
```

## Description

- `names = fieldnames(s)`: Returns a cell array of character vectors containing the field names of structure s.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
