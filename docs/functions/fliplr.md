# `fliplr`

Flip array left to right.

## Syntax

```matlab
B = fliplr(A)
```

## Description

- `B = fliplr(A)`: Reverses the order of columns of matrix A.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
