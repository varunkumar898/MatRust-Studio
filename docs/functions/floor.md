# `floor`

Round toward negative infinity.

## Syntax

```matlab
Y = floor(X)
```

## Description

- `Y = floor(X)`: Rounds each element of X to the nearest integer less than or equal to that element.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
