# `horzcat`

Horizontal concatenation.

## Syntax

```matlab
C = horzcat(A1, A2, ...)
```

## Description

- `C = horzcat(A1, A2, ...)`: Concatenates arrays horizontally along dimension 2. Equivalent to [A1, A2, ...].
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
