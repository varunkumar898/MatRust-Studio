# `imag`

Imaginary part of complex number.

## Syntax

```matlab
Y = imag(X)
```

## Description

- `Y = imag(X)`: Returns the imaginary part of each element of X.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
