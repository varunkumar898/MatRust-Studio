# imagesc

Display image with scaled colors.

## Syntax

`matlab
imagesc(C)
imagesc(x, y, C)
`

## Description

- imagesc(C) displays the data in array C as an image with scaled colors.
- imagesc(x, y, C) specifies image location coordinates.

## Example

`matlab
C = [1 2 3; 4 5 6; 7 8 9];
imagesc(C);
`
