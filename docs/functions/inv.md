# `inv`

Matrix inverse.

## Syntax

```matlab
Y = inv(X)
```

## Description

- `Y = inv(X)`: Computes the matrix inverse X^(-1) of square nonsingular matrix X using LU decomposition with partial pivoting.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
