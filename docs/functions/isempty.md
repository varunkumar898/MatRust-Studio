# `isempty`

Determine whether array is empty.

## Syntax

```matlab
tf = isempty(A)
```

## Description

- `tf = isempty(A)`: Returns true if array A has at least one dimension of size 0.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
