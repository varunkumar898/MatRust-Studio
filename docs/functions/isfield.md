# `isfield`

Determine whether input is structure array field.

## Syntax

```matlab
tf = isfield(s, field)
```

## Description

- `tf = isfield(s, field)`: Returns true if field is the name of a field in structure array s.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
