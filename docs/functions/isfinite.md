# `isfinite`

Array elements that are finite.

## Syntax

```matlab
tf = isfinite(A)
```

## Description

- `tf = isfinite(A)`: Returns true where elements of A are not NaN, Inf, or -Inf.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
