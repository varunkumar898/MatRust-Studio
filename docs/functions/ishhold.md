# `ishhold`

Query hold state of current axes.

## Syntax

```matlab
tf = ishold
tf = ishold(ax)
```

## Description

- `ishhold` returns logical `1` (true) if hold is on for the current axes, `0` (false) otherwise.
- `ishhold(ax)` returns the hold state of axes `ax` in the current figure.
