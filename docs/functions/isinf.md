# `isinf`

Array elements that are infinite.

## Syntax

```matlab
tf = isinf(A)
```

## Description

- `tf = isinf(A)`: Returns true where elements of A are Inf or -Inf.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
