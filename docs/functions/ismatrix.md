# `ismatrix`

Determine whether input is matrix.

## Syntax

```matlab
tf = ismatrix(A)
```

## Description

- `tf = ismatrix(A)`: Returns true if size(A) has exactly 2 dimensions.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
