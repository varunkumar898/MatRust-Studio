# `isnan`

Array elements that are NaN.

## Syntax

```matlab
tf = isnan(A)
```

## Description

- `tf = isnan(A)`: Returns true where elements of A are IEEE 754 Not-a-Number (NaN).
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
