# `isscalar`

Determine whether input is scalar.

## Syntax

```matlab
tf = isscalar(A)
```

## Description

- `tf = isscalar(A)`: Returns true if size(A) is [1, 1].
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
