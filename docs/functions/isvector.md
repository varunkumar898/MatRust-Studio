# `isvector`

Determine whether input is vector.

## Syntax

```matlab
tf = isvector(A)
```

## Description

- `tf = isvector(A)`: Returns true if size(A) is 1-by-N or N-by-1.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
