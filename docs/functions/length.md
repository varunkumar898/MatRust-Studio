# `length`

Length of largest array dimension.

## Syntax

```matlab
n = length(X)
```

## Description

- `n = length(X)`: Returns max(size(X)) for array X, or 0 if X is empty.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
