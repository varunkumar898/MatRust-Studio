# `linspace`

Linearly spaced vector.

## Syntax

```matlab
y = linspace(x1, x2)
y = linspace(x1, x2, n)
```

## Description

- `y = linspace(x1, x2)`: Generates a row vector of n equally spaced points between x1 and x2.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
