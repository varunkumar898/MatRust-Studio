# `load`

Load variables from MAT-file into workspace.

## Syntax

```matlab
load(filename)
```

## Description

- `load(filename)`: Loads variables from Level 5 or v7 MAT-file into the caller workspace.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
