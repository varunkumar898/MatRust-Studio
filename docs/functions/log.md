# `log`

Natural logarithm.

## Syntax

```matlab
Y = log(X)
```

## Description

- `Y = log(X)`: Computes natural logarithm ln(x) elementwise for each element of X.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
