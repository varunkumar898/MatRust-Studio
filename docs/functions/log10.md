# `log10`

Common logarithm (base 10).

## Syntax

```matlab
Y = log10(X)
```

## Description

- `Y = log10(X)`: Computes base-10 logarithm elementwise for each element of X.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
