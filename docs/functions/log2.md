# `log2`

Base 2 logarithm.

## Syntax

```matlab
Y = log2(X)
```

## Description

- `Y = log2(X)`: Computes base-2 logarithm elementwise for each element of X.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
