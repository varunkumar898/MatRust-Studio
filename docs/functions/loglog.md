# loglog

Log-log scale line plot.

## Syntax

`matlab
loglog(X, Y)
`

## Description

- loglog(X, Y) plots data using base-10 logarithmic scales on both x and y axes.

## Example

`matlab
x = 1:100;
y = x.^2;
loglog(x, y);
`
