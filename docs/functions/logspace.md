# `logspace`

Logarithmically spaced vector.

## Syntax

```matlab
y = logspace(a, b)
y = logspace(a, b, n)
```

## Description

- `y = logspace(a, b)`: Generates a row vector of n logarithmically spaced points between 10^a and 10^b.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
