# `lu`

LU matrix factorization.

## Syntax

```matlab
[L, U, P] = lu(A)
```

## Description

- `[L, U, P] = lu(A)`: Computes permutation matrix P, lower triangular L, and upper triangular U such that P*A = L*U.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
