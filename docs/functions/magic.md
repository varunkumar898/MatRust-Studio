# `magic`

Magic square.

## Syntax

```matlab
M = magic(n)
```

## Description

- `M = magic(n)`: Constructs an n-by-n magic square with sum of rows, columns, and diagonals equal to n*(n^2+1)/2.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
