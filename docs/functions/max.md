# `max`

Maximum elements of array.

## Syntax

```matlab
M = max(A)
M = max(A, [], dim)
[M, I] = max(A)
```

## Description

- `M = max(A)`: Finds largest elements along dimension dim, with optional linear index output.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
