# `mean`

Average or mean value of array.

## Syntax

```matlab
M = mean(A)
M = mean(A, dim)
```

## Description

- `M = mean(A)`: Computes the arithmetic mean along dimension dim.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
