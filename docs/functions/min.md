# `min`

Minimum elements of array.

## Syntax

```matlab
M = min(A)
M = min(A, [], dim)
[M, I] = min(A)
```

## Description

- `M = min(A)`: Finds smallest elements along dimension dim, with optional linear index output.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
