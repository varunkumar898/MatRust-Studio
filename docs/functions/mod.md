# `mod`

Modulus after division.

## Syntax

```matlab
M = mod(X, Y)
```

## Description

- `M = mod(X, Y)`: Computes modulus remainder after division: X - floor(X./Y).*Y.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
