# `ndims`

Number of array dimensions.

## Syntax

```matlab
n = ndims(A)
```

## Description

- `n = ndims(A)`: Returns the number of dimensions of array A (minimum 2).
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
