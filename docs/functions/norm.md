# `norm`

Vector and matrix norms.

## Syntax

```matlab
n = norm(A)
n = norm(A, p)
```

## Description

- `n = norm(A)`: Computes 1-norm, 2-norm, Frobenius norm, or infinity norm.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
