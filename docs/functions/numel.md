# `numel`

Number of elements in array.

## Syntax

```matlab
n = numel(A)
```

## Description

- `n = numel(A)`: Returns the total number of elements in array A: prod(size(A)).
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
