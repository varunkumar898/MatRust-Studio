# `ones`

Array of all ones.

## Syntax

```matlab
Y = ones(n)
Y = ones(sz1, ..., szN)
```

## Description

- `Y = ones(n)`: Constructs an array of specified dimensions with all elements equal to 1.0.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
