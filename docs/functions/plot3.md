# `plot3`

Plot lines and points in 3-D space.

## Syntax

```matlab
plot3(X, Y, Z)
```

## Description

- `plot3(X, Y, Z)` plots coordinates in 3-D space.
- `X`, `Y`, and `Z` must be vectors of equal length.
- Connects the points $(X_i, Y_i, Z_i)$ in 3-D using camera azimuth and elevation orthographic projection.
