# `prod`

Product of array elements.

## Syntax

```matlab
B = prod(A)
B = prod(A, dim)
```

## Description

- `B = prod(A)`: Computes product of array elements along dimension dim.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
