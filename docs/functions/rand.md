# `rand`

Uniformly distributed random numbers.

## Syntax

```matlab
R = rand(n)
R = rand(sz1, ..., szN)
```

## Description

- `R = rand(n)`: Generates array of pseudorandom values uniformly distributed on interval (0, 1).
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
