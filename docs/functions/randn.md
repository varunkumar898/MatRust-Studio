# `randn`

Normally distributed random numbers.

## Syntax

```matlab
R = randn(n)
R = randn(sz1, ..., szN)
```

## Description

- `R = randn(n)`: Generates array of pseudorandom numbers from standard normal distribution N(0, 1).
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
