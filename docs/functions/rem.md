# `rem`

Remainder after division.

## Syntax

```matlab
R = rem(X, Y)
```

## Description

- `R = rem(X, Y)`: Computes remainder after division: X - fix(X./Y).*Y.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
