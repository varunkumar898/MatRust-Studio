# `repmat`

Repeat copies of array.

## Syntax

```matlab
B = repmat(A, n)
B = repmat(A, sz1, ..., szN)
```

## Description

- `B = repmat(A, n)`: Tiles array A across the specified dimensions.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
