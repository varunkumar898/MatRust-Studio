# `rot90`

Rotate array 90 degrees.

## Syntax

```matlab
B = rot90(A)
B = rot90(A, k)
```

## Description

- `B = rot90(A)`: Rotates array counterclockwise by 90*k degrees in the first two dimensions.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
