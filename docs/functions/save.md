# `save`

Save workspace variables to MAT-file.

## Syntax

```matlab
save(filename, 'var1', ...)
```

## Description

- `save(filename, 'var1', ...)`: Serializes workspace variables into a Level 5 MAT-file with optional compression.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
