# `saveas`

Save figure to SVG file.

## Syntax

```matlab
saveas(filename)
saveas(h, filename)
```

## Description

- `saveas(filename)` saves the current figure as an SVG file.
- `saveas(h, filename)` saves figure `h` as an SVG file.
