# `sign`

Signum function.

## Syntax

```matlab
Y = sign(X)
```

## Description

- `Y = sign(X)`: Returns 1 for positive numbers, -1 for negative numbers, and 0 for zero.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
