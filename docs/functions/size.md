# `size`

Array dimensions.

## Syntax

```matlab
sz = size(A)
[m, n] = size(A)
d = size(A, dim)
```

## Description

- `sz = size(A)`: Returns the sizes of dimensions of array A.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
