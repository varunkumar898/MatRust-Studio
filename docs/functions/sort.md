# `sort`

Sort array elements.

## Syntax

```matlab
B = sort(A)
[B, I] = sort(A, dim, direction)
```

## Description

- `B = sort(A)`: Sorts elements along dimension dim in 'ascend' or 'descend' order.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
