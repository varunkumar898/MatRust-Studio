# `std`

Standard deviation.

## Syntax

```matlab
s = std(A)
s = std(A, w, dim)
```

## Description

- `s = std(A)`: Computes standard deviation along dimension dim with normalization weight w (default 0 for N-1).
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
