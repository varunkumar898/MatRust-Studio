# `strlength`

Length of string elements.

## Syntax

```matlab
L = strlength(S)
```

## Description

- `L = strlength(S)`: Returns the number of characters in each string or character vector element.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
