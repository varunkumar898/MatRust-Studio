# `struct`

Create structure array.

## Syntax

```matlab
s = struct(field1, val1, ...)
```

## Description

- `s = struct(field1, val1, ...)`: Constructs structure array with specified field names and field values.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
