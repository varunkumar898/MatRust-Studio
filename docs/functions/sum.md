# `sum`

Sum of array elements.

## Syntax

```matlab
S = sum(A)
S = sum(A, dim)
```

## Description

- `S = sum(A)`: Computes the arithmetic sum of elements along dimension dim.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
