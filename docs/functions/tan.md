# `tan`

Tangent of argument in radians.

## Syntax

```matlab
Y = tan(X)
```

## Description

- `Y = tan(X)`: Computes tangent of each element of X in radians.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
