# `trace`

Sum of diagonal elements of matrix.

## Syntax

```matlab
t = trace(A)
```

## Description

- `t = trace(A)`: Computes the trace of square matrix A: sum(diag(A)).
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
