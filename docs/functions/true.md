# `true`

Logical true array.

## Syntax

```matlab
L = true(n)
L = true(sz1, ..., szN)
```

## Description

- `L = true(n)`: Creates a logical array with all elements set to logical 1 (true).
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
