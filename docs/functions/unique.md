# `unique`

Unique values in array.

## Syntax

```matlab
C = unique(A)
[C, ia, ic] = unique(A)
```

## Description

- `C = unique(A)`: Returns sorted unique values of array A with index vectors.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
