# `var`

Variance.

## Syntax

```matlab
v = var(A)
v = var(A, w, dim)
```

## Description

- `v = var(A)`: Computes variance along dimension dim with normalization weight w (default 0 for N-1).
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
