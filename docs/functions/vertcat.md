# `vertcat`

Vertical concatenation.

## Syntax

```matlab
C = vertcat(A1, A2, ...)
```

## Description

- `C = vertcat(A1, A2, ...)`: Concatenates arrays vertically along dimension 1. Equivalent to [A1; A2; ...].
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
