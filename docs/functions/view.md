# iew

Set 3-D graph camera viewpoint.

## Syntax

`matlab
view(az, el)
`

## Description

- iew(az, el) sets the azimuth and elevation angles of the camera viewpoint.

## Example

`matlab
surf(peaks);
view(45, 30);
`
