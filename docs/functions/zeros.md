# `zeros`

Array of all zeros.

## Syntax

```matlab
Y = zeros(n)
Y = zeros(sz1, ..., szN)
```

## Description

- `Y = zeros(n)`: Constructs an array of specified dimensions with all elements equal to 0.0.
- Implemented in RustLab following clean-room MATLAB-compatible specifications.
