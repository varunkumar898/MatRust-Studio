# Barnsley Fern Iterated Function System (IFS)

**Area**: Fractals & Chaos  
**Script**: `examples/math/fractals/barnsley_fern.m`  

## Mathematical Background

Constructs the self-affine Barnsley fern fractal attractor using a 4-rule probabilistic iterated function system (IFS).

## Expected Numerical Outcomes & Verification

- **Expected Results**: Dense self-similar fractal fern spanning x in [-2.5, 2.8] and y in [0.0, 10.0]
- All figures render with informative titles, axis labels, and legends where appropriate.

## Parameters to Vary

- Modify grid resolution, time spans, or solver options to explore system dynamics and stability.
- Adjust parameters to inspect sensitivity, convergence rates, and bifurcation transitions.
