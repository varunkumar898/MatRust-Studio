# Coupled Normal Modes & Resonances

**Area**: Linear Algebra  
**Script**: `examples/math/linear_algebra/eigen_modes.m`  

## Mathematical Background

Finds the eigenfrequencies and vibration mode shapes of a 3-DOF coupled spring-mass dynamical system.

## Expected Numerical Outcomes & Verification

- **Expected Results**: Natural frequencies omega = [sqrt(2 - sqrt(2)), sqrt(2), sqrt(2 + sqrt(2))] ~ [0.765, 1.414, 1.848]
- All figures render with informative titles, axis labels, and legends where appropriate.

## Parameters to Vary

- Adjust parameters to inspect sensitivity, convergence rates, and bifurcation transitions.
