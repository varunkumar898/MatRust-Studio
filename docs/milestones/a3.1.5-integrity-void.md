`scalar_integer_display_goldens` as executed tests. `git grep` at `35fb6f1` (A3.1.3 gate state) and

## 4. Evidence rule going forward

A number, transcript, log, or tool output is reportable only if the raw artifact is retained in the
repository (or a named durable path outside it). Anything else is marked **unverified** or **void**
in the same sentence, never presented as measured output.
